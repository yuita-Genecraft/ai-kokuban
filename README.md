# AI黒板（AI Blackboard）

スマホの画面に指で式を書くと、黒板がその式を読んで、曲線や立体をチョークで描きます。HTML 1枚・外部ライブラリなし・WebGL2。

**遊ぶ**：https://yuita-genecraft.github.io/ai-kokuban/ （スマホ縦向き推奨・iOS Safari／Android Chrome）

## できること
- 手書きの式（例：`y=x^2-3`・`z=sinxcosy`・`x^2+y^2+z^2=9`）を読んで、グラフや立体に
- 大きく書いて1行に入り切らない式は、下の段に続きを書ける（2段・3段を1つの式として読む）
- 粗い四角を描くと立方体として読んで、きれいに成形
- 曲線や立体に点を置いて引っ張ると、形と式がその場で変わる（3点まで）
- 「書けた」ボタンを押すと、手書きを読んで、整った字に直してから図にする（押すまでは読まない）
- 読み違えた字は「入力」で直すと、その人の字として覚える（端末の中だけに保存）
- 質感の切り替え・チョークの音

## 使い方
`index.html` をブラウザで開くだけ。サーバー不要。`?movie=1` でデモ動画の台本が動きます。`demo.mp4` はデモ動画（1080×1080・82 秒）。

## 手書きの読み取り
字の形を小さなニューラルネット（中間 384・重みは約 175 KB を HTML に埋め込み）で見分け、字の切り分け・肩の字（指数）・式として通るかを束探索で決めます。読み取りも計算もブラウザの中だけで動きます（サーバーへ何も送りません）。

本物の手書きの式 1,691 本（MathWriting から、このアプリで書ける形の式を取り出した物）での式まるごとの一致は、作り替える前 5.0%（85 本）→ 今 65.2%（1,102 本）です。小さく書いた指数・くっついた字・「x と y」「2 と z」のように形が似る字はまだ外します。

スマホの指では字が大きくなるので、式の続きを下の段に書けます。段は「上の段を書き終えてから、左へ戻って下に書いた」形で見分け、段をまたいで1つの式として読みます（かっこが段をまたいでもよい）。上の手書きの式のうち1行で正しく読めた物を、字の切れ目で折り返して置き直すと、2段では 92.8%（951 本中 883 本）、3段では 88.0%（650 本中 572 本）を同じ式として読みました。

重みの学習に使ったデータ（どちらも CC BY 4.0。大きさをそろえ、傾き・ゆがみ・震えを足して使いました）：
- Prat, F., Castro, M., Llorens, D., Marzal, A., & Vilar, J. (2008). UJI Pen Characters (Version 2) [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5FG8S
- Alpaydin, E. & Alimoglu, F. (1996). Pen-Based Recognition of Handwritten Digits [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5MG6K

精度の確かめにだけ使ったデータ（学習には使わず、同梱もしていません）：MathWriting（Google Research・CC BY-NC-SA 4.0）。
