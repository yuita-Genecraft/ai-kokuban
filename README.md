# AI黒板（AI Blackboard）

スマホの画面に指で式を書くと、黒板がその式を読んで、曲線や立体をチョークで描きます。HTML 1枚・外部ライブラリなし・WebGL2。

**遊ぶ**：https://yuita-genecraft.github.io/ai-kokuban/ （スマホ縦向き推奨・iOS Safari／Android Chrome）

## できること
- 手書きの式（例：`y=x^2-3`・`z=sinxcosy`・`x^2+y^2+z^2=9`）を読んで、グラフや立体に
- 粗い四角を描くと立方体として読んで、きれいに成形
- 曲線や立体に点を置いて引っ張ると、形と式がその場で変わる（3点まで）
- 「書けた」ボタンで、手書きの字を整えてから読む
- 質感の切り替え・チョークの音

## 使い方
`index.html` をブラウザで開くだけ。サーバー不要。`?movie=1` でデモ動画の台本が動きます。`demo.mp4` はデモ動画（1080×1080・82 秒）。
